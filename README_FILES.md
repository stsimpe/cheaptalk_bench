| Αρχείο | Σκοπός στην έρευνα |
|---|---|
| README.md | Η πλήρης περιγραφή του benchmark: τα ερευνητικά ερωτήματα και οι απαντήσεις τους, ο σχεδιασμός, και μία εντολή για κάθε ισχυρισμό της διπλωματικής. |
| config.py | Όλες οι ρυθμίσεις ενός πειράματος (παίγνιο, τοπολογία, σενάριο, μοντέλο, φίλτρο). Γράφονται σε κάθε run, ώστε να φαίνεται ακριβώς πώς έτρεξε. |
| games.py | Οι πίνακες αποδόσεων του Διλήμματος του Φυλακισμένου και του Stag Hunt, τα δύο παίγνια της μελέτης. |
| topology.py | Οι τοπολογίες δικτύου (αστέρας, δακτύλιος, clique, γραμμή): ποιος παίζει και ποιος μιλά με ποιον. Η βάση του RQ2. |
| prompts.py | Τα κείμενα που διαβάζουν οι πράκτορες: το παίγνιο, η θέση τους στο δίκτυο, το κανάλι και η μορφή της απάντησης. |
| message_policies.py | Τι περνά από το κανάλι σε κάθε σενάριο (κανονικό μήνυμα, σιωπή, άσχετο κείμενο, frames), και τα φίλτρα μηνυμάτων του RQ4. |
| agent.py | Ο πράκτορας: χτίζει το prompt από τη δική του θέα του ιστορικού, καλεί το μοντέλο και διαβάζει το μήνυμα ή την ενέργειά του. |
| engine.py | Ο βρόχος του παιγνίου: φάση μηνυμάτων, παράδοση κατά μήκος των ακμών, φάση ενέργειας, αποδόσεις ανά ακμή. |
| llm_client.py | Η σύνδεση με τα μοντέλα, τοπικά σε 4-bit στις GPU του Kaggle ή μέσω API. |
| run_all_scenarios.py | Τρέχει τα σενάρια ενός μοντέλου σε μία διεργασία και σώζει κάθε run ως JSON. |
| campaign.py | Ο εκκινητής κάθε καμπάνιας στο Kaggle: διαλέγει τις παραμέτρους ανά μοντέλο και session, ελέγχει τα runs που βγήκαν και τα πακετάρει. |
| requirements.txt | Οι βιβλιοθήκες για την ανάλυση και για τα μοντέλα μέσω API. |
| requirements_local.txt | Οι επιπλέον βιβλιοθήκες για τα τοπικά μοντέλα σε GPU. |
| analysis.py | Η κοινή βάση όλων των εργαλείων: μετατρέπει ένα run σε σύνοψη (συνεργασία, άκυρες, κέντρο και φύλλα), του δίνει την ετικέτα του κελιού του και βρίσκει τους φακέλους των runs. |
| cross_model_analysis.py | Συγκεντρώνει τα runs του πλέγματος σε πίνακες ανά κελί: μέσοι όροι, διαστήματα εμπιστοσύνης, διαφορά από την άγκυρα. |
| cross_model_plots.py | Τα γραφήματα του πλέγματος, από τους πίνακες του cross_model_analysis.py. |
| harm_ledger.py | Το ισοζύγιο ωφέλειας και βλάβης: κάθε κελί απέναντι στη δική του άγκυρα χωρίς επικοινωνία. Η άμεση απάντηση στο RQ1. |
| anchor_sensitivity.py | Πόσο αλλάζει το ισοζύγιο αν οι άκυρες αποφάσεις μετρηθούν με τον χειρότερο για την κουβέντα τρόπο. |
| attractors.py | Σε ποια κατάσταση καταλήγει κάθε run, και αν οι συνθήκες διαφέρουν σε αυτό (τεστ Fisher με διόρθωση Holm). |
| topology_compare.py | Αστέρας, δακτύλιος και clique ανά ερευνητικό ερώτημα. Η κύρια σύγκριση του RQ2. |
| topology_three_plot.py | Το γράφημα των τριών τοπολογιών, με κάθε run σχεδιασμένο. |
| hub_lag_test.py | Αν ο κόμβος-κέντρο του αστέρα οδηγεί τα φύλλα, με χρονικά υστερημένο τεστ. |
| message_corpus.py | Κάθε μήνυμα που στάλθηκε, μαζί με το τι έκανε μετά ο αποστολέας. Η βάση για την εξαπάτηση και τα φίλτρα. |
| filter_analysis.py | Ποιο φίλτρο μηνυμάτων αξίζει να δοκιμαστεί μέσα στο παιχνίδι, κρίνοντας από τα μηνύματα που ήδη υπάρχουν (RQ4). |
| rq4_filter_plot.py | Το γράφημα του RQ4: το ανταγωνιστικό κελί χωρίς φίλτρο, με στενό και με ευρύ φίλτρο, ανά μοντέλο. |
| llm_judge.py | Ο κριτής εξαπάτησης: ένα μικρό μοντέλο κρίνει αν ένα μήνυμα δεσμεύει τον αποστολέα σε συνεργασία. |
| deception_report.py | Ο ρυθμός αθετημένων υποσχέσεων, μόνο στα κελιά όπου ο κριτής επικυρώθηκε από ετικέτες με το χέρι. |
| harm_source_report.py | Πού γεννιέται η βλάβη της ανταγωνιστικής οδηγίας, και ποιος από τους δύο δρόμους τη μεταφέρει: ο πράκτορας που ξαναδιαβάζει το μήνυμά του ή αυτοί που το διαβάζουν. |
| clique_sh_report.py | Το Stag Hunt στην clique, κρινόμενο με τους κανόνες που γράφτηκαν πριν τρέξει: επανάληψη του ισοζυγίου, επίδραση τοπολογίας, άκυρες αποφάσεις. |
| commfix_report.py | Αν το διορθωμένο prompt δρομολόγησης άλλαξε τα κελιά του δακτυλίου, απέναντι σε κελί ελέγχου. |
| verify_prompt_bug.py | Οι τέσσερις έλεγχοι από τα logs που οριοθετούν το σφάλμα του prompt δρομολόγησης. |
| verify_prompts.py | Ξαναχτίζει κάθε prompt που είδε κάθε πράκτορας σε ένα run και ελέγχει ότι ήταν το σωστό. |
| audit_corpus.py | Ο έλεγχος ακεραιότητας των αρχείων: αποδόσεις, παράδοση μηνυμάτων, διπλότυπα, άκυρες αποφάσεις. |
| kaggle_runner.ipynb | Οι αρχικές καμπάνιες: το πλέγμα σε αστέρα και δακτύλιο, και τα frames στο system prompt. |
| kaggle_rq4_f1.ipynb | Το ευρύ φίλτρο μηνυμάτων (F1) του RQ4 μέσα στο παιχνίδι. |
| kaggle_commfix_ablation.ipynb | Ο δακτύλιος ξανά με το διορθωμένο prompt, για να μετρηθεί αν το σφάλμα άλλαξε κάτι. |
| kaggle_ring_competitive.ipynb | Τα δύο ανταγωνιστικά κελιά του δακτυλίου με το διορθωμένο prompt, στα οποία στηρίζονται το RQ3 και το RQ4. |
| kaggle_g2b_triad.ipynb | Ο αστέρας του gemma-2-2b ξανά και η clique του, για να κριθεί η αντιστροφή του στο RQ2. |
| kaggle_clique.ipynb | Η clique στο Δίλημμα του Φυλακισμένου, session A: το τρίτο σημείο του RQ2. |
| kaggle_clique_bc.ipynb | Η clique στο Δίλημμα του Φυλακισμένου, sessions B και C: τα frames στα μηνύματα και στο prompt. |
| kaggle_clique_sh.ipynb | Το Stag Hunt στην clique, με δύο μοντέλα παράλληλα σε κάθε session του Kaggle. |
| kaggle_harm_source.ipynb | Τα στοχευμένα κελιά για την πηγή της βλάβης: τίποτα δεν παραδίδεται, ο γράφων δεν ξαναβλέπει το μήνυμά του, ένας μόνο γράφων ανάμεσα σε ουδέτερους. |
| kaggle_judge.ipynb | Ο κριτής εξαπάτησης πάνω σε όλα τα μηνύματα του Διλήμματος του Φυλακισμένου. |

| notebooks/kaggle_E_bertrand_pilot_TEMPLATE.ipynb | Πρόταση για το επόμενο στάδιο: πιλοτικό τιμολόγησης Bertrand, για συμπαιγνία εις βάρος τρίτου. |
